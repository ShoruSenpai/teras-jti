# Laporan Analisis & Pengujian Fitur Non-UI (Background Logic)

Berikut adalah hasil analisis dan _debugging_ statis terhadap _source code_ frontend (Vue 3) untuk fitur-fitur kritikal yang berjalan di latar belakang (tidak terlihat langsung di UI). Analisis ini mencakup Route Guards, State Management, API Interceptors, dan _Security Validation_.

| No. | Skenario Pengujian | Test Case | Hasil yang Diharapkan | Hasil Pengujian (Analisis Statis) | Kesimpulan |
|:---:|:---|:---|:---|:---|:---:|
| 1 | **Router Guard** (Device Detection) | Akses rute *mobile* menggunakan *browser* Desktop | Guard mendeteksi `!isMobile()` (lebar layar > 1024px atau tanpa *touch capability*) dan me-redirect paksa *user* ke `/desktop`. | Logika deteksi `isMobile` dan pembatasan akses berjalan dengan benar. | ✅ **Valid** |
| 2 | **Router Guard** (Device Detection) | Akses rute desktop (`/desktop`) menggunakan *browser* Mobile (HP) | Guard mendeteksi `isMobile()` dan secara otomatis me-redirect paksa *user* ke `/` (Homepage Mobile). | Validasi lintas *device* berhasil dan mencegah HP membuka versi desktop. | ✅ **Valid** |
| 3 | **Router Guard** (Token Security) | Akses rute `/dine-in/{token}/...` menggunakan token URL yang **tidak sesuai** dengan Cookie | Guard memeriksa kesamaan token URL dengan nilai cookie `session_dine-in`. Jika tidak cocok/hilang, redirect ke `/?session=expired`. | Keamanan sesi terjamin, mencegah pencurian token hanya melalui URL. | ✅ **Valid** |
| 4 | **Router Guard** (Master Token Bypass) | Menggunakan token khusus *development* (contoh: `MASTER-DEV-DN`) | Guard mengenali daftar `MASTER_TOKENS` dan mengizinkan masuk walau tanpa kecocokan cookie untuk mempermudah QA/Debugging. | Fitur *bypass master token* berjalan eksklusif sesuai kode. | ✅ **Valid** |
| 5 | **Pinia Auth Store** (Session Isolation) | Inisialisasi sesi `dine-in` ketika *user* sebelumnya memiliki cookie `reservation` | Store `initializeAuth()` secara otomatis memanggil fungsi hapus cookie pada tipe sesi yang berlawanan untuk mencegah bentrok data/sesi ganda. | Cookie berlawanan dibersihkan dengan sukses (Isolasi berjalan). | ✅ **Valid** |
| 6 | **API Interceptor** (Auth Injection) | Menjalankan *request* API apapun setelah sesi token berhasil diset di Pinia | Axios _request interceptor_ (`apiClient.js`) secara global menyisipkan *header* `X-Session-Token` ke setiap *request* yang dikirim ke *backend*. | Tidak perlu menyelipkan token manual per-*request*. *Header* selalu tersisip otomatis. | ✅ **Valid** |
| 7 | **Session Service** (Geolocation Payload) | Proses inisiasi pembuatan sesi (`/session/create`) dari halaman utama | Fungsi membawa *payload* `latitude` dan `longitude` yang didapat dari HTML5 Geolocation API untuk divalidasi oleh backend (Geofencing). | Struktur *payload* valid dan siap divalidasi oleh sisi backend API. | ✅ **Valid** |
